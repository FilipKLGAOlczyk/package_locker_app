# Package Locker App 📦

An application simulating the operation of a package locker system. The project allows for managing lockers, clients, and various types of parcels (e.g., standard, express, insured).

## 🚀 Features

* **Client Management:** Adding and managing system users.
* **Locker Management:** Assigning parcels to appropriate dimensions and tracking locker statuses.
* **Parcel Management:** Handling different types of parcels (Standard, Express, Insured).
* **Unit Tests:** Verifying business logic using tests located in the `test/` directory.

## 🛠 Technologies

* **Language:** C++
* **Build System:** CMake
* **Documentation:** Doxygen
* **Architecture:** Structured into managers, repositories, and data models.

## 📁 Project Structure

The main directories in the project are:
* `library/` - Core application logic (models, managers, repositories) and tests.
* `program/` - Console interface / application entry point (`main.cpp`).
